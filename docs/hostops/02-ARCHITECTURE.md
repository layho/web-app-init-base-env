# Architecture
React/TypeScript Base shell -> Python gateway -> persisted job queue -> outbound authenticated HostOps agent -> fixed operation handlers. Separate host process from app and MacCI. Agent has its own unprivileged identity, no inherited MacCI token or SSH keys. Gateway cannot invoke shell. Agent validates signed job envelope and local policy, not just UI or server role. Host registry maps opaque IDs to local service identifiers. Initial handlers: heartbeat, health, service inventory, module digest inventory, bounded redacted logs. Mutations added only after security tests. Local spool and append-only event sequence; dedup by job ID and canonical parameter digest. At-least-once delivery, never claim exactly-once external effects. On lease expiry reconcile unknown mutation outcome before retry. No dependency on browser connection. HostOps unavailable during gateway outage unless local diagnostics are used; do not claim automatic recovery before testing.
