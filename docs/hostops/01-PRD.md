# HostOps V1.0 — approved product direction
Owner approved UI prototype and implementation direction on 2026-11-26. ChatGPT is sole primary developer; no multi-agent dependency. Goal: reduce manual Mac mini operations and deliver observable, recoverable operations without SSH after initial setup. One host service shared by Base and downstream apps; first rollout Mac mini/Base/Panel. No arbitrary remote shell in V1; terminal is a structured operation console. No GitHub Actions, direct production DB edits, credential exposure, or silent host privilege escalation. Design before execution. Milestones: read-only diagnostics, durable jobs, controlled operations, UI, actual ChatGPT integration, safe upgrade, Panel delivery, failure recovery. Existing backlog remains priority; HostOps is approved infrastructure exception.
