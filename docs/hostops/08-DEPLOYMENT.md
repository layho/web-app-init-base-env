# Deployment
Initial operator-controlled installation of separate unprivileged host identity/LaunchAgent; exact reviewed artifacts and independently obtained hashes; private state directory, scoped credentials, outbound TLS; no public SSH required. Keep MacCI existing services intact. Inventory actual labels and GUI domain; privileged broker design and approval required before controlling another user's jobs. Install after isolated tests and explicit host approval. Rollback retains prior verified module and never removes lock files. Upgrade through existing trusted installer where appropriate, with finite lock retry and postcheck; no remote policy self-update. Actual host restart/offline test required. Do not claim service loaded from source commit alone.
