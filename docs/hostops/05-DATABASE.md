# Persistence
Separate tables hostops_hosts, hostops_services, hostops_modules, hostops_tasks, hostops_task_events, hostops_task_logs, hostops_policies, hostops_approvals, hostops_audit. UUID job IDs, UTC timestamps, versioned schema, unique (actor,host,idempotency_key), unique (task_id,sequence), foreign keys and retention policy. Transactional claim using row lock/skip locked, compare-and-set lease and status. Task states CREATED WAIT_APPROVAL QUEUED CLAIMED RUNNING VERIFYING SUCCESS FAILED RETRYING TIMED_OUT CANCELLED UNKNOWN ROLLED_BACK. Terminal success only after evidence. Mutating UNKNOWN must reconcile before retry. Store bounded redacted output, not credential-bearing raw logs. Approval binds payload digest, scope, expiry, policy version. Migration verified in isolated environment; no direct production DB changes. Initial read-only prototype need not add production tables until gateway persistence is implemented.
