# Test plan
Unit: strict parameter validation, allowlist, canonical digest, redaction, output cap, cancellation, state transitions, expiry, idempotency. Integration: atomic claim, lease fencing, reconnect, duplicate report, stale worker, SSE resume, auth isolation. Security: malicious shell metacharacters, symlinks, traversal, injected env, forged signature, replay, privilege escalation, secret output, unapproved upgrade. Host: restart, gateway unavailable, receipt backlog, actual module digest, service status. UI: approved palette, six pages, truthful offline/loading/errors, mobile, keyboard navigation, logs. MacCI only, no GitHub Actions; isolated fixtures/no production DB. Preserve exact test evidence and failure logs. No host mutation tests on credential-bearing production host without explicit approval.
