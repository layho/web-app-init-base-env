# API contract
Prefix /api/hostops/v1. User routes: GET /hosts; GET /hosts/{id}/health, /services, /modules; POST /tasks; GET /tasks, /tasks/{id}, /tasks/{id}/logs, /tasks/{id}/events; POST /tasks/{id}/approve, /cancel, /retry; GET /audit. Agent routes POST /agent/heartbeat, /claim, /report. Separate authentication audience for each. Request {host_id,operation,parameters,timeout_seconds,idempotency_key,reason}; strict schema, reject unknown keys. Result {task_id,status,risk_level,approval_required,created_at,result}; result includes exit_code, elapsed_ms, verified evidence, truncation indicator. Idempotency scoped to actor/host/key; mismatched payload 409. Unauthorized 403, invalid 422, stale lease 409. Log/events use monotonic sequence cursor; SSE resumes from last event id; no secrets in events. Claim atomic with lease token, attempt, expiry. Report must match active lease and sequence. Initial operations host.health, service.inventory, module.inventory; service.kickstart deferred until broker approved. No arbitrary shell string accepted. API routes are design contracts, not implemented yet.
