# V0.6.0 W01 与 W02 计划

执行者：Grok。这是评审通过之后的开工划分，不是本 PR 的实现。契约保持草案。

完成分成四层，不能互相代替：

| 层 | 含义 |
| --- | --- |
| 阶段性实现 | 对应编号的代码已经存在，默认不接入生产门禁 |
| 隔离验证 | 在临时目录和测试身份上覆盖该编号的正反例 |
| 生产启用 | 真实身份、真实宿主或真实门禁开始使用它。高风险项另要用户授权 |
| 工作包最终验收 | 该包每一个原编号都有隔离验证。生产启用未做要单独写明，不能把“尚未启用”写成包已完成 |

仍读旧事件、文档说明、以及生产认证 diff 为空，都只可能是阶段性约束。它们不是 W01 或 W02 的最终验收。

W01 最终验收：F04、F05、D02、D06、D07 都有隔离验证，并且 outbox、inbox、reducer 三条都在。兼容旧事件只说明双读还在，不代替这三条。

## SLO 建议与测量

目标是提案。当前基线都是未知。没有样本时不能写成已经达到。

| 指标 | 建议目标 | 测量方法 | 当前基线 |
| --- | --- | --- | --- |
| 反馈同步延迟 | p95 ≤ 15 分钟 | 逐条反馈计算 synced_at 减 created_at，再对这个分布取 p95。不用某一小时最老一行的年龄代替 | 未知 |
| 成功写入已经落盘 | 100% 的成功 append 至少是 DURABLE_LOCAL | 写盘后、HTTP 前终止测试进程 | 未知 |
| 重放不推动第二次投影 | 额外投影次数为 0 | 重放夹具比较水位，并确认响应没有令牌 | 未知 |
| 旧序号覆盖新水位 | 0 次 | 先应用序号 2 所在流的缺口规则，水位不回退 | 未知 |
| 过期租约完成 | 夹具中全部返回 LEASE_FENCE_REJECTED | 服务端时钟超过 expires_at，或代次不一致 | 现有队列单测不覆盖这套 Run。生产命中率未知 |
| 活跃快照过期可见 | 失败后 120 秒内显示 stale | 两个快照文件的并发夹具 | 代码里有 120 秒和 600 秒阈值。现场样本未知 |
| 假最新 | 不健康时 update_no_change 为 0 | 隔离目录 | 未知 |
| 约定失败摘要 | pytest 与指定 TS 夹具提取率 100% | failure_summary 夹具 | 没有生产计数 |
| 部署中断 | 回执丢失进入 RECONCILE，不进入 COMMIT | 隔离环境记录 deployment_id | 未知。禁止在生产注入 |

一次成功不能写成 p95。p95 来自逐条反馈的延迟分布。
