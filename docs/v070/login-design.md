# V0.7.0 登录页设计 V1 — 已确认

用户已确认采用此 UI，并授权先上传设计。需求 #228。V0.6.0 完成交付前不启动 V0.7.0 实现，不合并 main/preview，不部署。

视觉原型：[login-preview.html](./login-preview.html)。独立静态 HTML/CSS/SVG，无外部资源、无真实认证或网络请求，仅用于设计验收。品牌切换器为预览工具，正式页面不显示。

## 规范
- 左品牌区域、几何立方体及网格，文案“让应用管理更简单。”，右侧居中登录卡片；移动端单列隐藏左侧装饰。
- 背景 #0B1017，卡片 #121B26，边框 #263445，强调 #4295FF，文字 #E8EEF5；圆角 8–12px。
- 顶部应用品牌和 WORKSPACE，底部 Powered by App Foundation；不暴露内部运行信息。
- 基座公共 LoginPage.tsx，派生应用通过允许公开的品牌配置独立显示应用名称、Logo；禁止按应用硬编码分叉。默认品牌基座工作台。
- 账号、密码、显隐、登录按钮、键盘 Enter、焦点、自动填充、提交中防重复、错误提示；保留 /api/login、会话、CSRF、限流及认证安全约束，不增加注册、找回密码、记住密码或新认证方式。

## 验收
1440/1280/1024/390/360 宽度截图、基座及派生应用品牌、成功及失败登录、键盘操作、密码显隐、重复提交、刷新会话恢复、认证回归。原型仅展示布局与基础交互，正式接线和浏览器验收待开发。
